Approach:

Using pwd i checked where i am, iam in /box so i needed to keep the content of where ever the DB_PASSWORD is (in .env file) inside db_password.txt in home directory which is EventApp
Finally, using cat EventApp/config/.env > EventApp/db_password.txt i have added the file inside db_password
